# 09. Data Lakehouse Storage

Data Lakehouses are a recent innovation in the data storage and analytics landscape, combining the characteristics of Data Lakes and Data Warehouses.

Data Lakehouse platforms aim to combine the storage of raw data with the performance and metadata management capabilities of Data Warehouses.

Below are some popular Data Lakehouse platforms:

- Delta Lake
- Databricks
- Snowflake
- Azure Synapse Analytics
- Starburst
- Apache Iceberg and Apache Hudi
- Dremio
