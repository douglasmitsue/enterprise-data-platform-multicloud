# 07. Structured Data Storage

Structured data consists of data that follows a predefined schema or model, typically organized into tables with rows and columns.

Here are some of the most common options for storing structured data:

**Relational Databases (RDBMS):** MySQL, PostgreSQL, Microsoft SQL Server, Oracle Database, and SQLite.

**Cloud Data Warehouses:** Amazon Redshift, Google BigQuery, and Snowflake.

**Cloud Storage Services for Structured Data:** Amazon RDS, Azure SQL Database, and Google Cloud SQL.

**Time-Series Databases:** InfluxDB and TimescaleDB.
