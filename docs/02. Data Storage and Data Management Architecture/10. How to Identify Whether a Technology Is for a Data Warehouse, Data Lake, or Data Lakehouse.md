# 10. How to Identify Whether a Technology Is for a Data Warehouse, Data Lake, or Data Lakehouse

Here are three general rules of thumb. While there are exceptions, they provide a good starting point:

- **Does the technology provide integrated data storage and analytics?**  
  Then it is probably a **Data Lakehouse** technology.

- **Does the technology allow you to store data in any raw format?**  
  Then it is probably a **Data Lake** technology.

- **Does the technology require data to be cleaned and processed before it is stored?**  
  Then it is probably a **Data Warehouse** technology.
