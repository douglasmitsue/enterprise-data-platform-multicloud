# 03. Types of SGBDs (DBMS)

- **Relational DBMS (RDBMS)** – MySQL, PostgreSQL, Oracle Database, and Microsoft SQL Server.
- **NoSQL DBMS** – MongoDB (document-oriented), Neo4j (graph-oriented), Cassandra (column-oriented), and Redis (key-value database).
- **Object-Oriented DBMS (OODBMS)** – ObjectDB.
- **In-Memory DBMS** – Redis and SAP HANA.
- **Distributed DBMS** – Cassandra and CockroachDB.
