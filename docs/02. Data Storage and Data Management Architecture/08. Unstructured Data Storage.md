# 08. Unstructured Data Storage

Unstructured data does not have a predefined format or follow a specific data model.

**Examples:** Text documents, images, videos, log files, and other unstructured content.

Here are some common options for storing unstructured data:

**Data Lakes:** Hadoop Distributed File System (HDFS), Amazon S3, Azure Data Lake Storage, and Google Cloud Storage.

**Object Storage:** Amazon S3, Google Cloud Storage, and Azure Blob Storage.

**BLOB (Binary Large Object) Storage:** SQL Server, Oracle Database, and PostgreSQL.
