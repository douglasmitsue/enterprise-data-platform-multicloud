
# 8. Architecture and Design

**Data Sources**: RDS databases, DynamoDB, text files, and external APIs.

**Extraction and Loading:** Use of AWS Lambda for serverless functions to extract, transform, and load the data.

**Storage:** Amazon Redshift with serverless data warehousing.

**Analysis:** SQL interface in Redshift and integration with Amazon QuickSight for visualization.

**Management and Orchestration:** AWS Step Functions to orchestrate Lambda functions.
