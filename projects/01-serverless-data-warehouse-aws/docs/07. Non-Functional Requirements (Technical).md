# 07. Non-Functional Requirements (Technical)

**RNF001:** The system must be scalable to support up to a 500% increase in data volume without performance degradation.

**RNF002:** Resilience – The system must be capable of automatically recovering from failures in the shortest possible time.

**RF003:** Cost – Optimization should target a pay-as-you-go model.

**RF004:** Security – All data must be encrypted in transit and at rest.

As an alternative solution to avoid computational overhead (caused by encrypting data in transit and at rest), data anonymization may be used.
