# 06. Functional Requirements

**RF001:** The system must be capable of extracting data from multiple sources, such as relational databases, NoSQL databases, text files, and APIs.

**RF002:** The system must transform the data according to the rules defined for each data source.

**RF003:** The DW must consolidate the transformed data from different sources.

**RF004:** The DW must support SQL queries for analysis.

**RF005:** There must be an interface for visualizing the generated insights.
