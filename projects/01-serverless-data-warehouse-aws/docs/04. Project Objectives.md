# 04. Project Objectives

- **Cost-Efficiency:** Reduce costs by adopting a serverless approach, where you only pay for what you consume.
- **Agility:** Enable analytics teams to access and process data in real time or near real time without the need to manage complex infrastructure.
- **Scalability:** Ensure the architecture can grow alongside the company, supporting data volumes without compromising performance.
- **Resilience and Security:** Keep data protected and encrypted while ensuring high availability and minimizing downtime.
